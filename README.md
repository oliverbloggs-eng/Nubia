# Nubia KC Estates Ltd website

- `index.html`: the full site in one file. Upload it to the repo root and turn on GitHub Pages (Settings → Pages → Deploy from branch → main / root).
- `source/`: editable design source (`Nubia Website.dc.html` + `support.js` + `assets/`). Open the .dc.html file in a browser to preview.

Notes
- Property, category and blog photos load from nubiakcestates.co.ke. Add the files to `source/assets/photos/` with the same names to host them here.
- The admin panel (footer → Staff login) saves changes in the visitor's browser only. A live admin needs a backend or CMS.
